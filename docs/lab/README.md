# Lab log

Running research notes for Yellowjacket, one file per line of inquiry, dated.
Each entry records: the question, what was measured or read (with file:line),
what was tried, what happened, and what is now settled. Entries are appended,
never rewritten, so a later reader can see how a conclusion was reached and
what it would take to overturn it. Settled findings are promoted to the
CONTRACT-*.md documents and to the README's "Numbers worth trusting".
